death By Sea

Death by Sea is a 2D vertical platformer that explores the dangers of irregular sea migration through mechanics-driven design. The player must ascend from deep water to the surface while avoiding hostile “Drowned” enemies that drain health on contact, emphasizing vulnerability rather than combat dominance.

Horror Lethal

A puzzle game set in a haunted hospital/house split into two parallel versions. Features a haunted version with a patrolling monster and a safe version where the player can explore freely. Core gameplay revolves around switching between versions to evade the monster and solve puzzles. One of the first games I developed, created with a classmate as part of a school project. Personally responsible for developing the entire game. Implemented player interactions using raycasting and event triggers.

The upside Castle

The Upside Castle is a 2D mobile game that introduces gravity flipping as a core mechanic. The player uses this ability to complete challenges and escape the castle. For The Upside Castle, I used rigidbody physics parameters combined with sprite flipping to create the illusion of a gravity shift.
